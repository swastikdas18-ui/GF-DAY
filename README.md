# Girlfriend Day Website Gift 🎁

Here is your custom-built, mobile-friendly web app!

## How to Set It Up:
1. Extract all the files from this ZIP.
2. In the `images` folder, place the 3 photos you shared. Ensure the file names match exactly what is in the code (or rename the files in the `index.html` file to match yours):
   - `WhatsApp Image 2026-08-01 at 02.30.58 (1).jpeg` (Main Hero image)
   - `WhatsApp Image 2026-08-01 at 02.30.58.jpeg` (Mirror image)
   - `WhatsApp Image 2026-08-01 at 02.30.59 (1).jpeg` (Beach image)
3. Open `index.html` in your browser to test it locally. 

## How to Publish on Netlify (Free & Fast):
1. Go to [Netlify Drop](https://app.netlify.com/drop).
2. Drag and drop the entirely unzipped folder (`gf_day_website`) into the upload box.
3. Netlify will instantly generate a live link you can share with her! 
   *(You can even change the site name in Netlify's Site Settings to something cute like `our-story.netlify.app`)*.

## How to Publish on GitHub Pages:
1. Create a new repository on GitHub (e.g., `gf-day`).
2. Upload `index.html`, `style.css`, `script.js`, and the `images` folder to the repository.
3. Go to Repo Settings -> Pages -> Select `main` branch -> Save.
4. Your site will be live at `https://yourusername.github.io/gf-day`.
